# 📊 DataDrishti – AI-Powered Data Analytics Platform

DataDrishti is an AI-powered data analytics platform designed to make data analysis simple and accessible for everyone. It allows users to upload datasets and transform raw data into meaningful visualizations, insights, and actionable information.

The platform is designed especially for small businesses and non-technical users who want to understand their data without requiring advanced knowledge of data analytics or programming.

## 🚀 Features

* 📁 Upload and process datasets
* 📊 Interactive data visualization
* 📈 Dashboard for analyzing important data
* 🤖 AI-powered data insights
* 💡 Actionable recommendations
* 🔍 Automated data analysis
* 📋 Easy-to-understand presentation of results
* 👥 Beginner-friendly interface

## 🎯 Problem Statement

Businesses generate a large amount of data through sales, customers, products, inventory, and other activities. However, analyzing this data manually can be time-consuming and difficult for users without technical knowledge.

DataDrishti aims to solve this problem by providing a simple platform that converts raw datasets into useful visualizations and insights, helping users understand their data and make better data-driven decisions.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/DataDrishti.git
```

### 2. Navigate to the Project Directory

```bash
cd DataDrishti
```

### 3. Install Required Dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

Open the local URL shown by Flask in your browser.
